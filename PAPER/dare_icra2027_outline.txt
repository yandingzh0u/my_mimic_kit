DARE: Differential Adversarial Reward Equalization for Humanoid Motion Imitation
================================================================================

ICRA 2027 稿件结构（与 icra2027_paper.tex 同步；排版在最终版统一调整）
=====================================================================

主线（一句话）
--------------

手工奖励把目标聚合变成逐动作调权重；learned differential reward 去掉了权重，但留下一个
必须逐动作调的正则系数 lambda，因为它同时决定两件事：critic 能多陡（几何）和典型残差被推
离零点多远（尺度）。DARE 把两件事拆开，各自不用可调数：几何按构造固定（语义直和 + 全层 SN），
尺度按闭式规则一次校准（kappa = ln16 / M_f）。

写作原则
--------

- 不防御、不针对；批评的是"梯度惩罚这个机制"：lambda 小 → critic 逼近 delta 函数、典型残差
  的 reward 和斜率都趋零、活着和改进都没奖励；lambda 大 → critic 过平、分不开细节、reward
  接近常数、只奖励活着。可用区间随动作变，所以要重调；已发表配置对不同 clip / 角色用了不同
  lambda（事实陈述，不说"官方"）。
- 所有数字必须被推导出来后才出现：
  reward r = beta*softplus(f) → 斜率 beta*sigma(f) → 只有斜率的过渡区里 reward 才响应
  → 平衡 BCE 的对称平衡 f(0)=+M/2, E f(Delta)=-M/2 → M 由函数类×数据决定、界只给上限
  → 过渡区宽度用 sigmoid 的标准 20%–80% 定义（rise time 的通行定义）→ w = ln16
  → 把 anchor 放在过渡区上端、典型残差放下端 ⇔ M = w → kappa = w / M_f。
- kappa 每个动作不同，但规则相同；类比 DiffNormalizer：规则共享、尺度依数据。
  措辞用 motion-agnostic closed-form calibration / no task-specific tuning；不说 parameter-free。
- 记号先定义再用；未完成的结果一律 \todo / \tbd。

章节
----

I   Introduction：多目标 → 手工奖励 Eq.(1) → learned differential 去权重 → lambda 的两难
    （几何与尺度被一个系数绑在一起）→ DARE 拆开：几何按构造、尺度按校准 → 四条贡献。
II  Related Work：A 人形模仿；B 对抗模仿与 learned reward（ADD 一句：GP 系数逐动作设）；
    C 稳定对抗学习（Qin 2020：非 Wasserstein 损失下 Lipschitz 约束控制的是 score 范围，
    范围的尺度重要）；D 多目标优化。
III Background：A MDP；B 多目标跟踪 + DeepMimic 24 个系数；C learned differential
    objectives：通式 Delta=(l^1..l^n) 每目标一项 → 跟踪实例用原始坐标；单点正类 ⇒ 无正则
    最优判别器是 delta 函数 ⇒ 需要 GP（Eq. add 带 lambda）⇒ 两种失败 ⇒ lambda 干两件事。
IV  DARE
    A  Learned differential reward：归一化器（前 1e8 样本估计后冻结，无偏置，零点不动）、
       Eq. delta、q_pi、加框 BCE loss（= Eq. add 去掉惩罚）。
    B  Equalized critic（几何按构造）：l^g 是 1-Lipschitz 零点归零 → 稠密层单位增益预算
       Eq. budget → 直和层 psi_g（l^g 的向量值推广）→ 主干 → 非扩张 → 每目标权重界
       Eq. weight → 加框 |g(0)-g(Delta)| <= ||Delta||。强调：等容量等增益，不等范数。
    C  Anchor calibration（尺度闭式）：Eq. reward、Eq. slope、Eq. symmetric、
       M = L_eff * E||Delta|| 由界不定 → 两种失败 = M 落在过渡区两侧 → Eq. width（20–80%）
       → 加框 Eq. kappa → 三条性质（零点不动、几何不动、无动作常数）→ reward 界与包络。
    D  Training + Algorithm 1（含校准步）。
    E  Reading the learned aggregation：credit / price / interaction（price 用 kappa 归一）。
V   Experiments
    A  Setup（含 t_f = 382 轮；随机相位 4096 条评估；completion 判据）。
    B  Cross-motion（Table II；Roll 完成整周翻滚 winding 1.02；Climb 全完成）。
    C  Where the critic operates（Fig. 2：M、斜率 vs 迭代，有/无 kappa；GP 三个 lambda）。
    D  Ablation（Table III：Flat+SN / Factorized+GP / Distance head / Tight Lipschitz /
       kappa=1 / DARE）。

VI  Conclusion。
